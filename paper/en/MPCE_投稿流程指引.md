## 第一步：注册 ScholarOne 账号

### 1.1 访问投稿系统
- 打开 https://mc03.manuscriptcentral.com/mpce
- 点击 "Create Account" 或 "Register Here"

### 1.2 填写注册信息
- **First Name / Last Name**: 填写英文姓名
- **Email**: 使用学校邮箱 (如 y24203228@mail.shiep.edu.cn)
- **Institution**: Shanghai University of Electric Power
- **Country**: China
- **Area of Expertise**: 选择与论文相关的领域关键词
- 设置密码并完成注册

### 1.3 注意事项
- 通讯作者（导师）也需要注册账号
- 注册邮箱需要能正常接收邮件（ScholarOne系统邮件可能被拦截，注意检查垃圾邮箱）
- 建议同时记住 User ID 和密码

## 第二步：准备投稿材料

### 2.1 必需材料

| 材料 | 格式要求 | 说明 |
|------|----------|------|
| **稿件 (Manuscript)** | PDF 或 Word | IEEE双栏格式，≤9页 |
| **Cover Letter** | 在系统中填写 | 说明创新点和期刊匹配度 |
| **图片文件** | TIF/EPS/JPG, ≥300dpi | 单独上传高分辨率版本 |
| **推荐审稿人** | 在系统中填写 | 建议3-5位 |

### 2.2 稿件格式 Checklist
- [ ] IEEE双栏格式 (IEEEtran模板)
- [ ] 总页数 ≤ 9页 (Original Paper)
- [ ] 摘要 150-250 词
- [ ] 关键词 4-6 个 (Index Terms)
- [ ] 标题 ≤ 50 词
- [ ] 参考文献 IEEE 数字编号格式 [1], [2]
- [ ] 图片 ≥ 300dpi
- [ ] 通讯作者信息完整

### 2.3 推荐审稿人准备
- 准备 3-5 位推荐审稿人
- 要求：非本单位、非合作者、近3-5年有相关发表
- 信息：全名、单位、邮箱、专业领域
- 方向建议：Physics-informed ML、电力负荷预测、VPP/可再生能源预测

## 第三步：ScholarOne 投稿操作流程

### 3.1 登录系统
- 访问 https://mc03.manuscriptcentral.com/mpce
- 使用已注册的 User ID 和密码登录
- 进入 "Author Center"

### 3.2 创建新稿件
1. 点击 **"Submit a Manuscript"** 或 **"Click here to submit a new manuscript"**
2. 选择稿件类型：**"Original Paper"**

### 3.3 填写稿件信息（逐步完成）

**Step 1 - Type, Title & Abstract**
- Manuscript Type: Original Paper
- Title: 填写论文标题
- Running Head: 简短标题（≤50字符）
- Abstract: 粘贴摘要文本
- Keywords: 添加 4-6 个关键词

**Step 2 - Authors & Institutions**
- 添加所有作者（First Name, Last Name, Email, Affiliation）
- 指定 Corresponding Author（通讯作者 = 导师）
- 确认作者顺序

**Step 3 - Cover Letter**
- 在文本框中粘贴 Cover Letter 内容
- 或上传 Cover Letter 文件

**Step 4 - Suggest Reviewers**
- 添加推荐审稿人信息（姓名、单位、邮箱）
- 也可添加 "Opposed Reviewers"（希望排除的审稿人）

**Step 5 - Upload Files**
- 上传主稿件 (Main Document)
- 上传图片文件 (Figures)
- 上传其他补充材料（如有）
- 系统会自动合并生成 PDF

**Step 6 - Review & Submit**
- 检查系统生成的合并 PDF
- 确认所有信息无误
- 点击 **"Submit"** 完成投稿

### 3.4 投稿后确认
- 系统会发送确认邮件到通讯作者邮箱
- 邮件中包含稿件编号 (Manuscript ID)
- 在 Author Center 可以随时查看稿件状态

## 第四步：投稿后跟踪

### 4.1 ScholarOne 状态含义

| 状态 | 含义 | 预计持续时间 |
|------|------|------------|
| **Submitted to Journal** | 已提交，等待编辑分配 | 1-3天 |
| **With Editor** | 编辑审核中（可能desk reject） | 1-2周 |
| **Reviewer(s) Invited** | 正在邀请审稿人 | 1-2周 |
| **Under Review** | 审稿人已接受并在审稿 | 6-10周 |
| **Required Reviews Complete** | 审稿意见收齐 | 1-2周 |
| **Decision in Process** | 编辑正在做决定 | 1-2周 |
| **Accept** | 录用 | — |
| **Minor Revision** | 小修 | 需2-4周内返回 |
| **Major Revision** | 大修 | 需4-8周内返回 |
| **Reject** | 拒稿 | — |

### 4.2 何时催稿
- **一般情况**：投稿后 3 个月未收到消息可发邮件催问
- **催稿对象**：编辑部邮箱 mpce@alljournals.cn
- **催稿模板**：

```
Subject: Status Inquiry - Manuscript ID: [你的稿件编号]

Dear Editor,

I am writing to inquire about the current status of our manuscript
entitled "[论文标题]" (Manuscript ID: [编号]), which was submitted
on [日期].

We would greatly appreciate any update on the review progress.

Best regards,
[姓名]
[单位]
```

## 第五步：审稿意见回复 (Response Letter)

### 5.1 收到审稿意见后
- 仔细阅读每条意见
- 制定逐条回复策略
- 与导师讨论修改方案

### 5.2 Response Letter 格式

```
Response to Reviewers' Comments

Manuscript ID: MPCE-XXXX-XXXX
Title: PhysFormer: ...

We sincerely thank the Editor and Reviewers for their constructive
comments. We have carefully addressed all concerns. Changes in the
revised manuscript are highlighted in blue.

─────────────────────────────────────────

REVIEWER #1

Comment 1: [原文引用审稿人意见]
Response: [你的回复和修改说明]
Action: [具体修改了哪里，如 "Section III-A, paragraph 2"]

Comment 2: ...
Response: ...

─────────────────────────────────────────

REVIEWER #2
...
```

### 5.3 修改原则
- **逐条回复**，不遗漏任何意见
- 对于不同意的意见，礼貌解释原因并提供证据
- 修改稿中用**蓝色标注**所有改动处
- 尽量在编辑给定的deadline前完成（通常2-8周）

---

## 第六步：修改稿提交 (Revision)

### 6.1 登录系统
- 登录 https://mc03.manuscriptcentral.com/mpce
- 进入 Author Center
- 找到需要修改的稿件，点击 "Create a Revision"

### 6.2 上传修改材料
- 上传 **Response Letter** (逐条回复文件)
- 上传 **修改稿** (标注修改处的版本)
- 上传 **干净版** (无标注的最终版，可选)
- 更新图片文件（如有修改）

### 6.3 提交修改稿
- 检查合并后的 PDF
- 点击 Submit 完成提交

---

## 第七步：Accept 后续流程

### 7.1 录用通知
- 收到 Accept 邮件后，论文进入出版流程
- 编辑部会发送 **Copyright Transfer Agreement**
- 签署版权转让协议（IEEE格式）

### 7.2 校稿 (Proof)
- 收到排版后的校稿 PDF
- 仔细检查：
  - [ ] 作者姓名和单位拼写
  - [ ] 摘要和关键词
  - [ ] 公式排版是否正确
  - [ ] 图表质量和标注
  - [ ] 参考文献格式
- 标注所有需要修正的地方并返回
- **通常需要 48-72 小时内返回**

### 7.3 上线
- 校稿完成后论文在 **IEEE Xplore** 上线
- 获得 DOI 号
- 可在学术数据库中检索

---

## 第八步：备选方案

### 若被 Desk Reject（1-2周内）
**立即转投 Electric Power Systems Research (EPSR)**
- 投稿系统：https://www.editorialmanager.com/epsr/
- 订阅模式免费（无需付APC）
- 审稿周期：4-6个月
- IF: 4.2, Q1
- 年发文量~1012篇，录用率较高

### 转投EPSR需要的调整
- 将稿件格式从IEEEtran转为Elsevier模板
- 参考文献格式可能需要微调
- Cover Letter中更新期刊名称
