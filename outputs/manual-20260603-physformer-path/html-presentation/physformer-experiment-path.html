EXPERIMENT CONTRACT

先固定任务契约：这不是单变量预测，而是异构 DVPP 的带符号聚合问题

预测对象

目标是未来多步 aggregate net power。净功率由 Load、PV、Wind、Battery power 按符号组合得到，SOC 作为电池状态约束/辅助信号。

输入边界

模型读取组件历史、天气未来量和时间结构。核心风险不是单个组件误差，而是组件误差在 signed aggregation 下如何相互抵消。

评估读法

aggregate MAE/MSE 判断调度可用性；component/theory MAE 判断物理分支质量；Val-Test divergence 判断先验是否只拟合了当前 portfolio。

MECHANISM: ERROR CANCELLATION

C08 解释悖论：aggregate 精度由组件误差的协方差结构主导

Var(e_net) = Σ Var(e_i) ± 2Σ Cov(e_i, e_j)
1.95xgru96 component variance
2.34xcovariance cancellation
79.8%cancellation ratio
关键PV 与 Battery error 的正相关最关键：两者在 net 方程中符号相反。
悖论组件预测更差的模型，可能 aggregate 更好；这不是噪声，而是 shared representation 的结构性效应。
禁区避免“aggregate 更好 = 物理更好”的弱推断。

REPORTING SPINE

最终汇报应落在三条贡献，而不是版本堆叠史

贡献1组件 token 分离给出当前最强 aggregate 模型，并显著降低跨 seed 方差。
贡献2C08/C10 提供诊断框架：aggregate 改善可能来自误差相关性，而非物理更正确。
贡献3A2-A5 证明固定物理先验在该设定下是过拟合放大器，负结果本身构成边界条件。

PhysFormer 的贡献不在“把物理先验越加越多”，而在用实验找到了 VPP 多组件预测中表示边界、误差相关性和泛化之间的真实约束。
