EPSR LaTeX Submission Bundle

Main manuscript source:
  Physformer_en_epsr_submit.tex

Why this folder exists:
  Elsevier's LaTeX instructions state that all source files must be uploaded
  in a single folder and subfolders should not be used. This bundle flattens
  the manuscript into one submission-ready directory.
