## 核心矛盾

1. **Val/Test 背离 (非过拟合)**: 验证最优 ≠ 测试最优。Train/Val gap 分析显示所有 4 个实验的 gap 在 Phase 2 均在**缩小**（Δgap ≈ −0.1），经典过拟合被排除。背离更可能源于 R20 提供了更好的优化景观（隐式正则化），而非 R8 过拟合验证集。
2. **battery_component_weight 的双面性**: B5 在训练中显著改善梯度对齐（V5.5a 早期 GradCos +0.941），但测试中 theory MAE 和 residual std 反而不如 B1（B5 可能过度约束了物理分支的自由度）。
3. **V5.4 的梯度消失 (非收敛)**: R8+B1 组合导致 GradNorm ~1e-9、GradCos 恒定为 0——物理层的 load/battery 分支完全退化，但 Codex 指出低范数下 GradCos 数值不可靠，可能是度量伪象。
4. **R20 泛化优势的条件性**: restart_t0=20 仅在 batt_w=1.0（V5.5b）下表现优异。当与 batt_w=5.0 组合（V5.5）时，反而产生最差结果——两个独立改良产生**消极交互**。
5. **Checkpoint 已是全局最优**: 所有测试从 best checkpoint 加载（非最终 epoch），排除了"训练退化导致测试差"的混淆。

## Train/Val Gap 分析 (2026-05-12T20:30 新增)

从 train.log 提取每 epoch 的 Train Loss 与 Val Loss gap:

| 实验 | Phase 2 mean gap | Gap trend (first→last 5) | 趋势 |
|------|:---------------:|:------------------------:|:----:|
| V5.4 (R8,B1) | −0.397 | −0.395 → −0.499 | **收敛** ✓ |
| V5.5 (R20,B5) | −0.440 | −0.439 → −0.523 | **收敛** ✓ |
| V5.5a (R8,B5) | −0.412 | −0.428 → −0.534 | **收敛** ✓ |
| V5.5b (R20,B1) | −0.416 | −0.435 → −0.539 | **收敛** ✓ |

**结论: 所有 4 个实验的 train/val gap 均在缩小（收敛），排除经典过拟合假说。** Val/Test 背离需从优化景观差异（R8 vs R20 的 LR schedule 对解空间遍历的影响）和 Phase 3 缺失两个角度解释。
